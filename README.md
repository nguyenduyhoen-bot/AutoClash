# AutoClash

Bot tự động chơi Clash of Clans (CoC) chuyên nghiệp, tối ưu hóa hiệu năng cao trên giả lập LDPlayer.

## Cập nhật & Phát hành
- Toàn bộ bản cập nhật mới được phát hành độc quyền qua [GitHub Releases](https://github.com/nguyenduyhoen-bot/AutoClash/releases).
- Ứng dụng tự động kiểm tra và đồng bộ phiên bản mới nhất qua trình cập nhật `Updater.exe`.
